# Cartilage grading: evidence for a focused semantic audit

The frozen report rubric is unchanged. Numbered grades need enough context to
identify their meaning; depth and qualifying region extent remain separate.

The official ICRS evaluation package defines grade 2 below half cartilage depth
and grade 3 beyond half depth. Grade alone does not supply this competition's
region-size requirement. [ICRS evaluation package](https://cartilage.org/wp-content/uploads/2024/07/ICRS_evaluation1-1.pdf)

Avoid the blanket claim that Outerbridge grades never encode depth. A 2024
original observer study explicitly uses a depth-based Outerbridge definition
for grades II and III in Table 1. This is evidence that the terminology has
depth-based usage, not proof of which system an individual MRI report uses.
[Mederake et al., 2024](https://onlinelibrary.wiley.com/doi/10.1111/os.14016)

The coordinator requested a separate source-based audit of earlier batch-000
cartilage decisions after reviewers identified ambiguous grade references.
Proposals must preserve original artifacts, distinguish supported retained
decisions from uncertainty, and undergo independent adjudication before any
release change. No grade-based automatic relabeling is authorized by this note.
The full training release remains unfinished.
