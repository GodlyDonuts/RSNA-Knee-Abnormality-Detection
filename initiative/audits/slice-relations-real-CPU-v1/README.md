The diagnostic admits one selected series from the exact2247-study training UID
roster and accepted cache/source proof. It checks original TAR identity, metadata,
compressed volume size/SHA, dtype/shape, protocol row and known patient geometry.
Six actual slices are resized to32 pixels only for this bounded CPU engineering
check. All twelve disease cells are masked and no disease-label table is parsed.
This is not the production224-pixel recipe or a clinical evaluation.

physical relation policy. Require finite real adapter gradients and a changed
zero-initialized residual, preserve a one-update frozen-base delta/AdamW/RNG
boundary, reconstruct from the official weights, replay the second update and
compare every decoded model/optimizer/RNG value and MRI-only logits exactly.
The auxiliary head is forbidden from executing during classification inference.
Original frozen tensors must remain unchanged at every delta boundary check.

existing accepted runtime on private node-local disk. It has no Git alternate
store dependency or network/package installation. One CPU,16GiB RAM,zero GPUs,
one-hour ceiling; existing accepted image/weight archives stay in place.
