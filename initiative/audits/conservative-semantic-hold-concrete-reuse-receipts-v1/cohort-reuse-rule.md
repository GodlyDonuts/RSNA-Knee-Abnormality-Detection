An unchanged current negative can be proposed for cohort reuse when both independent original source opinions support that negative, the reviewed annotation supports the exact current object, its nonempty evidence is an exact contiguous source quote, and no concrete contrary state, material evidence/scope objection or unresolved source correspondence remains. Completed source-based v2 target judgments are genuine existing evidence; a lexical discovery flag, absence of a supplemental pass, or a review-family name alone is not an error or proof that those judgments failed. A contrary original or supplemental source opinion requires a separate explicit discharge. Eligible existing routes are (a) the same author's personally written postfreeze reconsideration, (b) an actual original reviewed adjudication whose source-based rationale addresses the stated contrary issue, or (c) an accepted-current/root disposition addressing that issue. Bind the actual reason and exact contrary evidence IDs. Mere final/current equality, a quote-only correction, majority support, or a generic rejected-proposal status is insufficient. An old adjudication cannot discharge a later contrary source finding unless the new release-use decision explicitly considers it. Where the required authored reason or scope is absent, retain an exact `state_disagreement`, `evidence_reliability`, `incomplete_reliability_review` or `report_scope_ambiguity` hold; do not create synthetic clinical reconsiderations.
