The run bound 2,247 eligible optimization studies and 1,156 outer-fold studies. The next update never completed: its flushed log remained at update 22 for over ten minutes. Read-only on-node inspection found rank zero inside `cuStreamSynchronize`, H100 0 at 100% reported utilization and H100 1 idle; rank one was waiting. This is evidence of a runtime stall, not proof of a particular hardware root cause. No Xid or ECC error was observed in the available query.
