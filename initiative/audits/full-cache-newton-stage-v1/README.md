# Verified full MRI cache on Newton

The accepted series cache was staged on Newton as one deterministic USTAR archive. The local replay verified all 48,772 source files against the accepted lineage, resumed an interrupted remote prefix from 75,434,622,976 bytes, and published the complete 82,834,493,440-byte archive only after an independent remote full-file SHA-256 and TAR membership check. The final SHA-256 is `6acf433e16c4832503103dd045943bbafa01dfb65fde8f56d93911fe1caac338`; the 48,772 members contain 82,794,366,615 unpacked bytes. The local `completed.json` and Newton `remote-receipt.json` agree exactly. The archive remains on authorized private cluster storage; its large bytes are not in Git.

`plan.json`, `partial-inspection.json`, `progress.json`, `completed.json`, `remote-verified-partial.json`, and `remote-receipt.json` preserve the transfer and verification evidence. `files.json` binds each original small record by SHA-256. `production-stage-receipt.json` records that the hash-pinned ten-epoch launch script and production configuration were staged only; it did not submit a GPU job. This transfer proof does not establish H100 throughput or a Kaggle score. The accepted training masks and folds were unchanged.
