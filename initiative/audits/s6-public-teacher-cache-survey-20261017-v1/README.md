# Is there a released S6 teacher-output shortcut?

Actual authenticated read-only `ListDatasetFiles` for
`nartaa/rsna-knee-s6fall-weights`**version3** returned all **seven files** with
pagination exhausted, total200,500,299bytes, matching its dataset card. They are
the original checkpoint, DONE/config/README, two manifests and the256,011byte
source/runtime extras archive. There is **no released fitting prediction,
logit or feature array in this version**. This is narrower than a claim about
every public dataset or unpublished author artifact.
[Actual complete listing](actual-complete-listing.json),
[exact read-only program](program.py.txt).

The earlier `GetDataset` card had an empty `files` field; that was not evidence
of an empty dataset. The installed official SDK identifies `ListDatasetFiles`
and its version/page fields, which were used for the complete listing. The
existing exact extras manifest names source/runtime members, not a hidden
training-prediction table. [Original extras membership](original-code-extras-members.json).

No weight/pixel/label bytes, Dataset/notebook, GPU job or competition entry were
acquired or created by this survey. Do not repeat the200MB weight download to
look for teacher targets. Bounded original inference is still needed for the
complete fitting outputs unless a separately justified source is discovered.
