## Proposed decision rules

1. **Validate before disposition.** Match the canonical UID×target, exact source/index/report/rubric, original/current annotation objects, actual authors and source/postfreeze selectors. Invalid or missing provenance fails the release check; inventing a hold with unbound evidence is not a workaround. 2. **Keep already-masked cells masked.** Current `uncertain` or `not_mentioned` requires zero non-gold report loss. Preserve every unresolved semantic obligation and correspondence reason, but require no new reading merely to keep this zero. Apply the same accounting to correspondence-excluded cells; exclusion is not clinical clearance.
3. **Retain an observation through an explicit reuse receipt.** Reuse original independent source/preread passes or supplemental full-target source passes with their real scopes. Require support for the current state and relevant criterion, a valid adequate quote/context, and a disposition for every known material objection. A later accepted adjudication can supply this disposition when its actual source-based rationale addresses the contrary evidence; correction-registry membership alone cannot. Root need not perform another full-source pass for an already supported, issue-resolved pair merely to approve its release use.
4. **Treat source agreement as evidence, not a vote.** Initial disagreement followed by an explicit personally authored reconsideration is preserved history, not automatically a continuing hold. Conversely, a rejected proposal, majority agreement or the latest timestamp does not discharge a contrary source/rubric rationale. If that rationale remains genuinely open, hold the current observed target as `state_disagreement`; leave its clinical state untouched.
5. **Classify quote differences by effect.** Body versus impression, a complete shorter diagnostic sentence, headings, punctuation and image locators can all support the same state. Record `adequate_variant` and reuse the observation when no material qualification is lost. Do not manufacture clinical evidence corrections just to make bytes equal. If an omitted referent, negation, temporal/causal qualification, anatomical scope or severity threshold changes or obscures support, record an `evidence_reliability` obligation. An existing full-context source disposition may settle it in a bound reuse receipt; a substring check or two matching proposal quotes cannot. A materially deficient current quote remains unresolved until an explicit evidence-completion/release-use disposition or accepted evidence correction addresses it. Preserve the original quote in either route.
6. **Hold a finite incomplete review scope honestly.** If a gate-relevant observation has only reading-count evidence, or its existing rationale does not address the actual reliability question, use `incomplete_reliability_review` with exact membership and an explanation. This does not diagnose an error. Missing a supplemental pass by itself is not such a question: an adequate original pair may be reused. Missing a lexical trigger is not clearance either.
7. **Do not guess unassigned cue targets.** First join the cue to existing full-source target readings and any explicit scope/nonclinical disposition. Reuse a previously authored localization or exclusion only when the exact cue and source are bound. If meaningful report scope remains unresolved, propose a `report_scope_ambiguity` hold enumerating all 12 cells of that report, with overlapping reasons retained. Do not expand every unassigned or date/comparison cue into an all-target hold automatically.
8. **Preserve lifecycle and separation.** A changed current state, quote, source, correction case or relevant opinion invalidates the affected reuse/hold binding. A hold is removed only by an explicit bound release disposition, not by a new correction or later matching opinion. Labels, quotes, source history, groups and accepted/retired correction objects remain unchanged. Gold values are never used to select holds; downstream gold precedence and evaluation-only handling remain the existing contract.

A reuse receipt should identify the exact cell set and evidence selectors; list each obligation and `resolved_for_release`, `held` or `already_masked`; name the adequate-quote relation and actual supporting authors; and cite the decision addressing any contrary history. An approved cohort receipt may enumerate cells satisfying the same already-authored disposition. It must not classify rationale text or infer clinical states with new lexical rules. If the authored evidence is insufficient, the finite fallback is a hold, not an unbounded reread assignment.
