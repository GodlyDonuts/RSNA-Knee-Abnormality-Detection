# Full-encoder paired-view teacher ordering

A distinct hypothesis: retain the original observed-source BCE while replacing half of the teacher BCE contribution with a between-study ordering loss, computed on the same mean-of-two-view probabilities used at inference. This targets ordering rather than forcing exact teacher calibration. It is not a new theory or established clinical gain. Weighted RankNet is the precedent ([Burges et al., 2005](https://www.microsoft.com/en-us/research/publication/learning-to-rank-using-gradient-descent/)); [Yuan et al., ICCV2021](https://arxiv.org/abs/2012.03173) is evidence that objective alignment can matter in medical classification, but its margin/min-max method is different and its reported gains do not predict knee performance.

The previous `ranking_context_train.py` experiment trained a frozen 402,956-parameter feature head against weak source labels; it did not couple teacher ordering through the entire73,136,096-parameter encoder. This mechanism changes neither model capacity nor serving cost. The earlier whole94 experiment already trained the full checkpointed encoder and scored0.949; it is not repeated or claimed as new.

`teacher_pair.py` computes teacher ordering from detached mean-view probabilities, weighting directed pairs by their positive teacher-probability gap, without inventing ties. Student ranking uses stable log-odds of mean-view probabilities, not averaged logits. Pair mass is normalized separately for each target. Original observed-source BCE remains exactly intact, including masked-label handling; a target with no pairs retains exact original BCE. The fixed half-teacher replacement is predeclared, not tuned against protected data. Both arms use identical original MRI, frozen BN statistics, source labels/masks, parent model, proposals and per-study IID16 windows/opposite views. Complete effective batches retain checkpointed encoder graphs; no new replay algorithm is added.

`compiler.py.txt` derives a separate single-rank numerical engine from the exact e024a8ee source; it leaves the original live engine, AdamW/LR/GradScaler/clipping/checkpoint/RNG behavior unchanged. Seventeen CPU tests check independent scalar math, teacher detachment, exact source contribution, tails/ties/extremes/views, sampling, and actual emitted-engine full/stop1/resume equality for both objectives including all optimizer/RNG/history/snapshot/prediction bytes. These are engineering evidence only.

`stage_once.py.txt` requires actual original CPU971665 input/model admission, exact original private source/dependency hashes, privately preserved new source, fresh quota and physical2H100 evc48. It links existing small source modules and adds only new own modules, creates an eight-study private input binding and admits CPU imports. It can submit exactly one1H100/twoCPU/32GiB/20minute probe. Existing stage or intent forbids another mutation. No raw data/model copy, optimizer update, checkpoint, validation score or Kaggle mutation is authorized by this probe.

`gpu_probe.py.txt` compares original sequential paired pointwise gradients with coupled pointwise and teacher-ranking gradients on the same eight original fitting studies. All73M parameters must have finite gradients, original parameter versions/BN buffers stay unchanged and forward-end RNG states match. Predeclared engineering tolerances: pointwise relative L2<=0.005 and cosine>=0.99999 separately for encoder/head/all; all phases peak below64GiB. Same fixed1024 loss scaling/unscaling is used in each phase; actual real trainer GradScaler/optimizer recovery is still a separate requirement. Input/first-render timing is not a fair throughput estimate or full-cohort runtime prediction. Ranking must produce a nonzero gradient change; that is not accuracy.

After an actual probe result, require a distinct funded real-GPU new-engine full/stop/resume acceptance before full training. Any accuracy experiment needs a matched pointwise control, fixed-final evaluation and actual competition/runtime acceptance. Do not use partial S6 ranks, protected gold/confirmation or diagnostic models. The complete original S6 teacher, six existing followers and frozen numerical sources continue unchanged. Current best remains the external0.958 reproduction; no original gain is claimed.
