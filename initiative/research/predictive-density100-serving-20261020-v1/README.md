# C100 final serving contract and offline compiler

Prepared, not deployed. This separate adapter accepts architecture C only with
the explicit C100 branch and coefficient100. It requires exact accepted pilot
and full-run source/job/terminal bindings, all six verified five-object private
publications, and the unchanged MRI inference modules.

The original serving contract's model export, T4 precision and CSV checks are
reused in an isolated module. Original B/C/C0 contracts are unchanged and still
reject coefficient100. Candidate identity becomes
`predictive-C100-epoch-006.pt`.

The separate [compiler](compile.py) is now implemented and locally tested. It
compiles one actual fixed-final C100 export into either a two-T4 qualification
or competition notebook. It keeps the original worker, MRI modules, bounded
mount discovery, exact descriptor reuse and public-only600-second watchdog
unchanged. The generated runtime exposes the C100-specific export and
qualification checks to that same worker; a C0.1/B/C0 acceptance cannot stand
in for C100's own measured qualification.

The 57 contract/compiler checks include strict trained-final admission, generated
runtime tensor/buffer validation, unchanged numerical source, and rejection of
another model, Dataset, worker, helper or qualification receipt. They use
synthetic evidence fixtures and establish engineering behavior only. No actual
C100 source was compiled from production weights: none exist yet.

This is not runtime acceptance, account allocation, competition submission or
accuracy. Actual final weights, a funded final-only return if needed, trained
T4 qualification and extra Kaggle capacity remain required. The primary
3,360-second reserve remains. No remote operation was made by this work.

[contract.py](contract.py) and [focused tests](test_contract.py).
