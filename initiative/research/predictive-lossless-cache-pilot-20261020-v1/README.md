# Actual-source lossless predictive cache pilot

This separate CPU-only gate reuses the original67raw DICOMs on owning33. It
compiles original integer samples/encoding metadata plus exact detached64D
source descriptors into a private compressed cache, then independently restores
all metadata-scaled pixels, both source-masked encoder contexts, descriptors,
observation masks, metadata queries and complete support priors. Every tensor
must be bit-identical to the uncached source path, with global RNG unchanged.
No labels, reports, models, optimizer, GPU or new source acquisition.

New private scope64MiB data/4MiB controls, zero shared bytes/files, after old
12GiB diagnostics/128MiB case and all other source reserves. The original staged
684b02a7 GPU numerical sources remain unchanged; this is a new future loader
optimization requiring actual-source acceptance before any full-cohort use.
Source lineage follows original HF52f995f4, never the old lossy percentile cache.
One small case cannot establish full-source encoding support or throughput.
